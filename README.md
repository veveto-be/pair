# 페어 핵심 요약 템플릿 v2

각지고 정렬된 레이아웃 + 자유 테마 컬러 선택이 가능한 버전입니다.

## 변경점
- 둥근 카드 / 캡슐 디자인 제거
- 모든 박스를 직선형으로 변경
- 정렬선과 테두리 중심의 레이아웃
- 컬러 피커로 테마색 자유 변경
- HEX 직접 입력 가능
- 선택한 색상 자동 저장
- PNG 저장 시 선택한 테마색 반영
