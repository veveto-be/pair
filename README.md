# 페어 핵심 요약 템플릿 v3

완전 각진 버전입니다.

## v3 변경점
- 카드, 입력칸, 버튼, 박스, 컬러 피커까지 border-radius 0 강제
- 모든 요소에 `border-radius: 0 !important` 적용
- GitHub Pages 캐시 방지를 위해 `style.css?v=3`, `script.js?v=3` 사용
- 기존 둥근 스타일이 남아 있어도 새 CSS가 우선 적용되도록 처리

## 업데이트 방법
기존 저장소의 `index.html`, `style.css`, `script.js`를 v3 파일로 덮어쓰세요.
그 뒤 GitHub Pages 화면에서 강력 새로고침(Ctrl+F5)하면 됩니다.
